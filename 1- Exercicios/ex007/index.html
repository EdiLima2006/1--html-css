Listas Ordenadas

todas aquelas lista onde a ordem dos itens é algo muito importante. Para criar a lista vamo usar a tag < ol >, para deliminar os itens vamos usar a tag < li >

A tag < ol > possui um parâmetro type, onde modificamos o tipo de marcador 1, A, a, I, i.

Você também pode pode indicar o inicio da contagem usando o parâmetro start

  1. item 1
  2. item 2
  3. item 3

Listas Não Ordenadas

Listas onde a ordem dos itens não importa.

Para usarmos ela vamo utilizar a tas < ul > para delimitar a lista usamos a tag < li >

type = disc, circle, square

  • Arroz
  • Feijão
  • Leite
  • Sal
  • Farinha
